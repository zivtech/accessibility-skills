## 2. OVERFLOW mechanism receipts (unscored, 1 × model, pinned fixture)

The same DUMP-sized prompt (est. 30,490 tokens) sent at num_ctx=32,768 produced **two
distinct failure modes** — exactly the mechanism documentation the receipt row exists for:

| model | done_reason | what actually happened |
|---|---|---|
| qwen3.6:35b | `length` (output_clipped) | prompt ate the window (prompt_eval 30,079/32,768); generation ran out of room mid-response |
| qwen3:32b | `stop` — looks normal | **silent server-side prompt truncation** (prompt_eval 28,445 < 30,490 sent); model "completed normally" on an input it never fully saw |

The 32b mode is the insidious one: nothing in the response signals truncation. This is the
live confirmation of the Phase 0 guard's reason to exist (and of F13's declared-ceiling fix).

## 4. Registered predictions (thresholds verbatim from §6; adjudicated)

- **P1 (local dilution): NOT SUPPORTED.** net(CURATED@40K − DUMP@40K) = **−4**
  (35b 14 v 17, 32b 16 v 17). The predicted CURATED advantage did not appear. The reverse
  direction exceeds the ±2 variance band mechanically, but no reverse-direction claim was
  pre-registered, and the decomposition above shows the −4 is ~3 parts flip-prone
  heading#item1 + 1 part a single-cell stable miss — we report **"DUMP wins" as provisional,
  not a registered conclusion**. What IS licensed: curation delivers no pack-scale accuracy
  gain on these models.
- **P1b (local fit): threshold VIOLATED, in the safe direction.** net(CURATED@32K −
  CURATED@40K) = **+4** (35b 17 v 14, 32b 17 v 16). The feared 32K deficit did not appear —
  32K cells beat 40K cells. Both CURATED@40K cells are the grid's weakest; same two items
  as above. Flagged for BENCHMARK.md per the registered rule (R5 input, not a conclusion:
  with this decomposition it is consistent with draw variance).
- **P2 (hosted non-inferiority harm-check): HOLDS, exactly.** net = **0**; opus and sonnet
  are 18/18 in both conditions — CURATED loses nothing. **Scope caveat (registered):** this
  is a pack-scale (~20K) result only; it licenses no claim about session-scale payloads.
  **Measurement ceiling caveat (F1 sense):** hosted recall is pinned at max in all four
  cells, so the hosted grid cannot discriminate payloads on recall at all; the only hosted
  signal that moved is FPs (below).
- **P3 (FP directional, DUMP ≥ CURATED): SPLIT.**
  - Hosted: **consistent** — DUMP 10 v CURATED 7.
  - Local: **AGAINST, on both models** — CURATED@40K 19 (35b 10 + 32b 9) v DUMP@40K 10
    (35b 3 + 32b 7); CURATED@32K higher still (22). Local models fabricate MORE violations
    on CLEAN fixtures under curated evidence than under the dump. Registered as
    directional-only/least-confident; the reversal is consistent across both local models
    and is the lane's most surprising exploratory finding. Hypothesis (labeled, untested):
    a compact digest hands the local model few, high-salience evidence rows it then
    over-interprets into violations, where the dump's bulk dilutes fabrication pressure the
    same way it dilutes attention. A follow-up would need CLEAN-heavy cells to test this.

## 5. Pre-committed decision rules — which branch fired

Nearest registered branch: **"P1 null + P1b null + P2 holds"** (P1 here is worse than null
for the prediction; P1b violated in the unfeared direction). Consequence, in the plan's own
words: **curation delivers no pack-scale accuracy gain; Phases 1–2 stand on cost/latency/
longevity grounds; R5 resolves to map hygiene (correct num_ctx entries), no further
curation lanes.** Additionally P2-holds confirms the Phase 2 reader's default-delegation
safety at pack scale (the harm-check it was powered for). The P3-local reversal is new
information the registered rules did not anticipate — it goes to the Phase 4.3 R5 memo,
NOT directly into routing text. **No routing guidance (BENCHMARK.md / CLAUDE.md) is
changed by this document.**

## 6. Instrument findings (scorer calibration, from adjudication deltas)

- **REPHRASED-FOUND = 49** item-draws (~27% of genuine finds): the keyword scorer's
  candidate counts under-report found items heavily — models report defects in words the
  per-item keyword lists don't cover. **SPURIOUS-MATCH = 1** (32b, heading#1: keyword hit
  without the actual finding). Direction is almost purely too-strict, never too-loose —
  the safe failure mode for a candidate detector, but candidate-level condition deltas were
  badly distorted (candidate table had DUMP leading by +3–5 where adjudicated truth is ±1
  per model). **Never read this lane's candidate counts as results** — the scorer's own
  docstring says so; this run measured why.
- CLEAN-row verdict quality (adjudicated `row_verdict_appropriate_for_clean=false`):
  concentrated in local CURATED cells (2–3 per cell) vs 1 per local DUMP cell; hosted:
  opus 1/8, sonnet 4/8 rows. Consistent with the local P3 reversal.
- One REAL-FP class worth naming: hosted models **computing** failures from pack evidence
  on CLEAN fixtures (opus filing a 2.27:1 focus-ring 1.4.11 failure and a ~380px reflow
  1.4.10 failure from curated numbers). Under the lane's frozen ground truth these are FPs;
  they are a different failure mode from the local models' fabricated-defect FPs
  (e.g. 35b's CRITICAL missing-h1 on the page-shell — the known over-flagging class).

## 7. Negative space — what this run does NOT establish

- Nothing at session scale (163–349-turn payloads); pack scale (~20–32K) only.
- No hosted payload-accuracy difference is measurable here (recall ceiling); the hosted FP
  delta (10 v 7) is 2-model × 4-CLEAN-row × 2-draw data — directional only.
- "DUMP beats CURATED locally" is NOT a licensed conclusion (see P1 decomposition).
- No local model's CLEAN verdict became trustworthy: 19–22 adjudicated fabricated
  violations across local CURATED CLEAN rows re-confirm detector-not-verdict-authority.
- Adjudication is single-adjudicator-per-fixture (opus, ground-truth-loaded); no
  second-adjudicator agreement pass was run.
